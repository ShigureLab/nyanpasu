# ast-grep skill

Optional. It teaches the agent to formulate and validate syntax-aware searches, useful for tracing code patterns across a repository.

## Prerequisites and installation

Install the [ast-grep CLI](ast-grep.md), then follow the [official agent-skill installation guide](https://github.com/ast-grep/agent-skill). One supported method is:

```bash
npx skills add ast-grep/agent-skill
```

This method requires [Node.js/npm](nodejs.md). The upstream guide also provides a Claude Code plugin installation method. Select the backend and user scope used by Nyanpasu, following [skill management](skill-management.md).
